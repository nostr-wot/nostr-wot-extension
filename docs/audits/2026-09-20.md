# 0.8.0 release audit — 2026-09-20

Scope: experimental WoT changes since 0.7.2 and the updated approval, account-copy and tooltip components. Review covered opt-in/site authorization, account changes, private mute handling, oracle bounds, graph persistence, automatic/manual sync, menu permission scope and documentation.

## Findings and remediation

- Sync released its single-flight guard before the completion-status write settled. Hold it through finalization; the regression test delays that write and verifies another sync is rejected.
- The root README still described the removed WoT implementation, and release/build docs still described 0.7.2. Update the feature guide, architecture/security/message-flow references, release instructions and proposal index for 0.8.0.
- Separate PQC canonical-draft shortcuts from the experimental WoT browser API/scoring proposals. No draft is represented as an accepted NIP.

## Verification

The full suite passed 1,716 tests with zero failures (216 crypto, 242 wallet, 264 pure/UI checks, 994 module tests). Build and type checking passed. A fresh isolated Chrome test saved, reloaded and deleted a 44,289,068-byte graph with 600,000 people.

Targeted tests exercise per-type allow/deny persistence, one-time actions, copy-menu keyboard/failure behavior, score results, account database actions and sync finalization. The full test runner builds the main clone before testing. Type checking and lint are release gates; ten existing hook-dependency warnings remain, with no lint errors. npm audit reported zero vulnerabilities on this audit date.

Native Chrome checks use isolated fixtures for the real UI components and generated CSS: both compact approval menus remain within a 400px viewport and exactly match their button anchors. Existing isolated Chrome IndexedDB testing covers a 44.3 MB graph roundtrip. These checks do not establish installed-extension worker survival during an unlimited live crawl, or live interoperability with every oracle and remote signer. Graph results may be incomplete; private mutes require locally available keys. This release does not claim to fix the previously unverified native Amber delivery behavior.

No unresolved blocking issue was identified within this review’s scope. This is a source and regression review, not an independent penetration test. Package reproduction compares every extracted file and its bytes against a clean install from the attached source ZIP; ZIP timestamps are excluded. Release artifacts include store packages, source, concise notes and SHA-256 checksums.
