# Proposal documentation

PQC proposals in `pqc/` are compatibility pointers to https://github.com/nostr-wot/nostr-pqc/tree/main/nip-drafts; edit the canonical PQC proposals there. WoT proposals in `wot/` describe the experimental browser API implemented in this extension. Clearly distinguish proposals from accepted NIPs and current implementation limits from interoperability requirements. Keep prose paragraphs on single source lines.
