# Signing proposals

Status: experimental, unnumbered drafts. They describe local and same-device signing contracts the Nostr WoT wallet implements on iOS and the client library that speaks it; they do not claim adoption by other signers or approval as NIPs.

1. [Same-device signing on iOS](01-ios-same-device-signing.md): the share-sheet transport, NIP-55's methods in batches, App Attest caller identity, the connect link and signing sessions over loopback.

[How to propose it upstream](PUBLISHING.md) · [All proposals](../README.md)

2. [Local signer bridge over Wi-Fi and Bluetooth](02-local-signer-bridge.md): authenticated local sessions, BLE framing, permissions and public test vectors. This draft records current implementation gaps and is not an accepted NIP.
