Nostr WoT 0.7.0

Security and privacy
- Encrypt cached balances, payment data and activity history with a vault-protected key.
- Strengthen account and vault-session isolation for signing and payments; cancel stale operations after lock, account switch or wallet replacement.
- Preserve existing site connections while distinguishing protocol and port for new permissions.
- Improve automatic-payment budgets, invoice validation, wallet transport and request limits.
- Update vulnerable dependencies and Firefox data-consent disclosures.

Wallet and payments
- Fix NWC connection/startup and intermittent "vault is locked" messages.
- Show cached wallet information while refreshing and load settled transactions past pending invoices.
- Accept pasted LNURL-pay strings and lightning:LNURL links.
- Improve WebLN capability detection and website payment compatibility.
- Refine wallet settings, profile-address state, deposit and send dialogs.

Accounts and approvals
- Group concurrent requests with readable event types, origins and expandable details.
- "Approve once" and "Approve all" apply only to displayed requests. "Always allow" separately saves permission for future requests.
- Reject foreign-account signing requests and show rejection summaries with a red toolbar counter.
- Improve account switching, sub-account creation and deletion confirmations.
- Preview npub and hex automatically, allow custom account names, and expose validated derivation paths under Advanced.

Post-quantum keys and interface
- Import encrypted seed and post-quantum backups, including pasted JSON.
- Improve post-quantum key management and publication status.
- Redesign profile, activity and shared controls; support cover-image uploads and local event decryption.
- Fix repeated relay requests and relay-list discovery.
- Improve scrolling, spacing, copy controls and keyboard accessibility.

Firefox requires desktop 140+ or Android 142+ for built-in data consent.
